# About Runshot

Runshot helps developers **inspect and share what a command actually did**.

It sits between a raw terminal and full observability stacks:

- lighter than Datadog / OpenTelemetry / LangSmith for everyday scripts  
- richer than `tee`, `script`, or copying CI logs by hand  

## Who it is for

- Frontend / backend engineers debugging `npm test`, builds, and migrations  
- ML / data folks wrapping Python training or ETL scripts  
- Anyone who wants a **portable HTML artifact** of a failed run
